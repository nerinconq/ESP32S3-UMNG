Propuesta de Integración para Exportación de Datos Experimentales

UMNG — Physys Lab v9.1 — Mayo 2026

🔴 Problema Actual

Los datos copiados al portapapeles desde Physys Lab están en formato JSON, pero Desmos Graphing Calculator necesita datos en formato TSV (Tab-Separated Values) para crear tablas automáticamente al pegar.

📋 Copiar Datos
JSON
→
📱 Portapapeles
→
📉 Desmos
❌ No reconoce

Lo que se copia actualmente:

{ "sensor": "ToF", "data": [{"t":0,"d":150.3}, {"t":10,"d":148.7}, ...] }

Lo que Desmos necesita (TSV):

t(ms) distancia(mm) 0 150.3 10 148.7 20 145.2 30 139.8

💡 Soluciones Propuestas

📋
A: Botón "Copiar para Desmos"
Modificación mínima en app.js

Agregar un botón dedicado en el modal de exportación que copie los datos al portapapeles en formato TSV (Tab-Separated). Al pegar en una línea vacía de Desmos, se genera automáticamente una tabla con las columnas correctas.

Dificultad
Baja
Tiempo Est.
15 min
Impacto
Alto
  • Funciona en celular y PC
  • Sin dependencias externas
  • Compatible con Excel y Sheets
  • Límite Desmos: 1000 filas
  • El usuario debe abrir Desmos manualmente
  • Requiere pegar en línea vacía

🔗
B: Enlace Directo a Desmos
Desmos API — Estado calculadora como URL

Generar un enlace que abra Desmos en una nueva pestaña con los datos ya cargados como tabla. Utiliza la API de Desmos para construir un estado de calculadora serializado en la URL, incluyendo las columnas de tiempo y medición.

Dificultad
Media
Tiempo Est.
2-3 hrs
Impacto
Muy Alto
  • Un clic: datos en Desmos
  • No requiere pegar nada
  • Se puede compartir el link
  • Requiere internet activo
  • Límite de URL (~8KB datos)
  • API key de Desmos necesaria
📈
C: Desmos Embebido en Physys Lab
Iframe + Desmos JS API

Integrar un calculador Desmos directamente dentro de la interfaz web de Physys Lab como una pestaña o vista adicional. Los datos del sensor se inyectan automáticamente a la gráfica Desmos usando calculator.setExpression() sin que el usuario tenga que copiar nada.

Dificultad
Alta
Tiempo Est.
5-8 hrs
Impacto
Premium
  • Experiencia completamente integrada
  • Gráfica en tiempo real posible
  • Cero pasos para el usuario
  • Requiere WiFi con internet
  • Aumenta peso de la UI (JS externo)
  • API key + términos de uso Desmos
  • Conflicto con modo AP sin internet

🎯 Recomendación: Implementación Progresiva

Empezar con la Solución A que es inmediata y resuelve el 90% del problema. Luego, en una fase posterior, agregar la B como mejora premium.

1
Fase Inmediata — Botón "Copiar para Desmos" (TSV)
Agregar botón en el modal de exportación que formatea los datos como columnas separadas por tabulación. Funciona offline, en celular y PC. Compatible con Desmos, Excel, Google Sheets y cualquier app que acepte tablas.
2
Fase Futura — Enlace Directo a Desmos (API)
Cuando haya conectividad a internet disponible, generar un botón "Abrir en Desmos" que lance la calculadora con los datos precargados. Requiere investigar la API de Desmos para estados serializados.
3
Descartada — Embebido en PWA
Descartada porque Physys Lab opera mayormente en modo AP (sin internet). El iframe de Desmos requiere conexión externa, lo cual contradice la arquitectura offline-first del instrumento.
